# HighBeam · Astara Intelligence presentation

Presentación interactiva de Astara Intelligence con **HighBeam Intelligence Suite** como motor principal.
Un único archivo (`index.html`) con sus imágenes en `assets/`; no necesita servidor ni dependencias.

## Cómo verla

Abre `index.html` en el navegador (doble clic). Para pantalla completa pulsa **F**.

## Controles

| Acción | Efecto |
|---|---|
| Clic, `Espacio`, `→`, `Enter` | Avanzar un paso |
| `←`, `Backspace` | Retroceder |
| `1`–`9` | Ir a una escena |
| `F` | Pantalla completa |
| Barra inferior | Saltar entre bloques (Methodology, Impact, Solutions, HighBeam) |

Enlaces directos: `index.html#5.2` = escena 5, paso 2.

## Escenas incluidas

1. Intro · 2. Methodology (iceberg) · 3. Impact · 4. Solutions (hub) · 5. HighBeam · 6. HighBeam / Strategy (DCI)

Pendiente: Marketing (APR), Product (Model Diagnosis), Retail y Pricing.

## Notas

- Diseño fluido para escritorio y tablet; móvil, pendiente.
- Una sola tipografía: Manrope (cargada desde Google Fonts).
- Las imágenes de `assets/solutions/hub-platforms.png` y `hub-highbeam.png` son provisionales y se pueden sustituir por otras con el mismo nombre.
- Los datos mostrados en el DCI son de ejemplo (*Sample data*).

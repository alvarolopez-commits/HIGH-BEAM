# HighBeam · Astara Intelligence presentation

Presentación interactiva de Astara Intelligence con **HighBeam Intelligence Suite** como motor principal.
Un único archivo (`index.html`) con sus imágenes en `assets/`; no necesita servidor ni dependencias.

## Cómo verla

Abre `index.html` en el navegador (doble clic). Para pantalla completa pulsa **F**.

## Controles

| Acción | Efecto |
|---|---|
| Clic, `Espacio`, `→`, `Enter` | Avanzar un paso |
| `←`, `Backspace` | Retroceder |
| `1`–`9` | Ir a una escena |
| `F` | Pantalla completa |
| Barra inferior | Methodology, Impact y Solutions (con HighBeam al pasar el ratón) |
| Barra superior (HighBeam) | Saltar entre productos |

Enlaces directos: `index.html#5.2` = escena 5, paso 2.

## Escenas incluidas

1. Intro · 2. Methodology (iceberg) · 3. Impact · 4. Solutions · 5. HighBeam (suite de cinco módulos) · 6. Strategy (DCI) · 7. Marketing (APR) · 8. Product (Model Diagnosis) · 9. Retail (Retail Analytics) · 10. Pricing Intelligence · 11. All together
